## 2. 设计方向

**命题**：一个私人的「新闻情报工作台」——上传新闻 PDF，提问，沿时间线读事件，最后写成报告。产品气质取自编辑部与档案室：冷静的纸面、清晰的层级、精确的时间轴。

### 2.1 色彩（冷纸 + 墨蓝，5 个主值）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#f2f3f5` | 应用底色，冷灰纸面 |
| `--surface` | `#ffffff` | 卡片、正文、浮层 |
| `--ink` | `#1b1d21` | 主文字，冷近黑 |
| `--muted` | `#6b7178` | 次要文字 |
| `--line` | `#e4e7ea` | 分隔线 |
| `--accent` | `#2a4a6b` | 墨蓝，唯一强调色 |

辅色只保留语义用途：`--green #2e6b55`（完成）、`--danger #a33f35`（危险）、`--marker #f3e7b6`（正文高亮）。旧的亮蓝 `#2563eb` 全部替换为墨蓝系。

### 2.2 字体（两族，分工明确）

- **界面**：`"Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", system-ui, sans-serif`——所有按钮、表单、列表、元信息。
- **文档/品牌**：`"Cambria", "Georgia", "Songti SC", "SimSun", serif`——仅用于字标（AiViewNews）与文档标题音色；正文阅读页在 PLAN 21 接入。
- 数字统一 `font-variant-numeric: tabular-nums`（日期、时间、计数），**不使用等宽字体做小标签**。
- 字号阶梯：11 / 12 / 13 / 14 / 15 / 17 / 21 / 34，正文 14，行高 1.6。

### 2.3 版式与结构

保持三栏布局与所有尺寸变量不变，只重做质感：

```
┌──────────┬──────────────┬──────────────────────────────┐
│ AiView   │ 记录/查询     │                              │
│ —        │ ┌──────────┐ │        正文（下一批）          │
│ 搜索     │ │ 问题输入  │ │                              │
│ ＋新建   │ │        ▶ │ │                              │
│ ───────  │ └──────────┘ │                              │
│ 历史条目 │ 时间线轴     │                              │
│ ┃ 当前   │ ├─ 06-12     │                              │
│          │ ├─ 07-03     │                              │
│ 头像     │ └─ 08-19     │                              │
└──────────┴──────────────┴──────────────────────────────┘
```

- 侧栏是**平面纸面 + 1px 分隔线**，不用卡片堆叠；阴影只给浮层（账户菜单、模态）。
- 圆角分级：4（小件）/ 8（控件）/ 12（面板）/ 16（模态）/ 50%（仅头像），不再全站同一个圆角。
- 历史/记录条目改为「左侧 2px 标记 + 平面底色」，代替通用胶囊选中态。
- **时间线是本批的视觉主角**：1px 轴线 + 空心方形节点 + 等宽数字日期；选中节点填充强调色。其余元素保持安静。
- 登录页：冷纸 + 极淡横线稿纸纹理 + 衬线字标与短下划线；选项卡改为底线式，不用胶囊。

### 2.4 原则

1. 用结构表达信息（轴线、分隔线、层级），不做纯装饰。
2. 只在一处用力：时间线；其他地方收敛。
3. 动效只回应操作（模态入场、hover/active），不加入场动画雨。
4. 可访问性：可见键盘焦点、对比度达标、`prefers-reduced-motion` 降级。

### 2.5 对照 SKILL.md 的「模板化特征」自检

- 不用暖米色 + 高对比衬线 + 陶土色；不用近黑 + 酸性绿；不做零圆角报纸版式；不套「同圆角 + 同灰阴影」卡组。
- 不新增大写眉标、中点拼接的 meta、等宽小标签、文案后缀箭头。
- 唯一衬线只用于品牌/文档音色，界面仍是克制的无衬线。

## 3. 方案

### 3.1 全局基础（`web/style.css`）

- 重写 `:root` 令牌（上述色板 + 圆角/阴影/字体/缓动），保留旧变量名 `--bg / --rail / --rail-2 / --accent-dark / --shadow` 以免其他样式断链：`--bg` 指向纸面色，`--rail`/`--rail-2` 指向两级浅灰。
- 基础排版、`::selection`、`:focus-visible` 焦点环、全局输入框基线（边框/圆角/焦点环/placeholder）。
- 按钮体系重做：主按钮（墨蓝、8px 圆角、按下位移）、幽灵按钮（描边 + 悬停浅蓝底）、危险按钮、图标按钮（28px）、链接按钮；统一 140ms 过渡与禁用态。
- 模态：半透明冷色遮罩 + 轻微模糊；卡片 16px 圆角 + 浮层阴影；**一次**入场动画（180ms），并尊重 `prefers-reduced-motion`。
- 细滚动条、统一空状态与错误文本。
- **登录页样式移出**到新文件 `web/auth.css`，避免 `style.css` 超过 300 行。

### 3.2 登录/注册（新增 `web/auth.css`）

- 极淡横线稿纸底纹 + 顶部柔光；居中卡片 400px。
- 字标改为衬线 + 30px 墨蓝短下划线（移除首字母变色）。
- 选项卡改为底线指示器；输入框浅底、聚焦转白；游客按钮虚线描边；小屏收紧。

### 3.3 历史侧栏（`web/history.css`）

- 工作区白底、侧栏浅灰、1px 分隔；上下留白加大到 16px。
- 字标衬线 16px + 短下划线；搜索框、`＋ 新建` 改为平面描边控件。
- 历史条目：去掉胶囊底色，改左侧 2px 标记；选中为白底 + 墨蓝标记 + 轻微阴影；元信息 11px 等宽数字。
- 头像加内描边，账户菜单 10px 圆角 + 浮层阴影。

### 3.4 记录侧栏 + 时间线（`web/records.css`）

- 记录列表同历史条目语言；查询框 12px 圆角、聚焦浅蓝环、右下圆形运行按钮（带极浅投影）。
- 拖拽条（`query-resize`）做成居中细握把，默认低对比、悬停加深。
- 时间线：1px 轴线；节点为 8px **空心方形**，悬停浅底，选中填充墨蓝；日期 11.5px 半粗等宽数字；正文 12.5px；摘要条左侧 3px 强调线。

### 3.5 伸缩与响应（`web/layout.css`）

- 手柄命中区不变（宽 11px），可视线改为 2px 圆角；悬停/拖拽用墨蓝低透明度。
- 保留 900/760px 断点与收起态尺寸，只调整间距与分割线。

### 3.6 上传空状态（本批纳入）

- 登录后无历史时的首屏就是上传区，纳入本批以保证第一印象一致；`reader.css` 只动 `.upload-pane / .upload-card / .upload-plus / #upload-status`。
- 卡片改为白底 + 1px 虚线、16px 圆角；加号改为描边圆环；悬停浅蓝底 + 极浅阴影。正文阅读、文档标签、简介面板仍留给 PLAN 21。

### 3.7 加载

- `web/index.html` 在 `style.css` 后引入 `auth.css`；静态资源版本 `?v=25` → `?v=27`（中途改过 `reader.css`，升到 27 强制刷新缓存）。
