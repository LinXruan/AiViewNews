# PLAN 22 — 视觉重构（三）：报告页、管理台、设置面板与收尾

日期：2026-11-18　｜　状态：已完成

> 全站美化第三批，也是收尾批。延续 PLAN 20/21 的令牌与语言；只改 CSS，不动任何交互逻辑、DOM 结构、id、接口。

## 1. 需求

- 完成剩余三块界面的统一：分析报告页、管理控制台、设置/个性化弹窗。
- 处理前两批遗留的旧蓝色硬编码（#2563eb / rgba(37,99,235) / #f7faff / #ffe58a 等），让全站只剩 PLAN 20 的墨蓝体系。
- 补一次键盘焦点与窄屏的走查。

## 2. 现状

- report.css：编辑器浅底 + 预览白底，但预览标题全无衬线，分隔条是蓝色 hover，状态条常驻空白。
- admin.css：卡片堆叠尚可，但所有卡片同圆角同阴影、表单控件与全局新令牌不统一；管理台任务表的状态徽标（.status.*）**完全没有样式**，只显示纯文本。
- settings.css：PLAN 19 建立，已继承新令牌，但圆角/字号与 PLAN 20 的控件语言还可以再收一格。
- 旧蓝色：report.css 的 focus/hover 阴影、admin.css 的 #fbfcfe/#f7faff，需一并替换。

## 3. 方案

### 3.1 报告页（web/report.css）

- 头部：白底 + 1px 下线，标题 16px / 600，右侧保存（主按钮）与下载（幽灵按钮）不变。
- 状态条：改为浅灰文字条；为空时用 :empty 隐藏，避免常驻空白行。
- 栅格：编辑区与预览区各 12px 圆角；中间分隔条默认透明，悬停/拖拽时显示 2px 墨蓝细线（与侧栏手柄一致）。
- 编辑区：等宽字体、浅底、13px / 1.8，聚焦转白 + 墨蓝环。
- 预览区：文档音色——h1/h2/h3 衬线（26 / 19 / 16），h2 带 1px 下划分节；正文 14.5px / 1.85；表格用底部细线与表头灰色；引用块左 3px 墨蓝线；行内代码浅蓝底。
- 窄屏（≤820px）保持单列、隐藏分隔条、两区最小 320px。

### 3.2 管理台（web/admin.css）

- 头部白底 + 1px 下线；内容列最大 1080px 居中，卡片 12px 圆角 + 1px 线，不再叠加同款阴影。
- 表单：输入/下拉统一浅底、8px 圆角、聚焦走全局墨蓝环；候选路径按钮由虚线块改为浅底描边。
- 表格：表头 11.5px 灰、底部细线；行悬停浅蓝底；数字使用 tabular-nums。
- **补齐状态徽标** .status 及 done/ready/parsed、analyzing/pending/parsing/draft、partial、failed 四组语义色（细描边 + 浅底）。
- 用户色点、事件日期、只读报告框统一到令牌；详情面板改浅底。
- 窄屏（≤720px）表单单列，内容内边距收紧。

### 3.3 设置/个性化（web/settings.css）

- 卡片 480px、24px 内边距；选项行 12px 圆角、13.5px 标题 / 11.5px 说明，悬停浅蓝底 + 墨蓝箭头。
- 调色盘：色块 8px 圆角、选中墨色描边；自定义取色器与预览区沿用令牌；状态行 12px。
- 小屏收紧内边距。

### 3.4 收尾

- 全站 CSS 搜索并清除旧蓝色硬编码，只保留 --accent 体系。
- 检查 :focus-visible 在按钮、链接、输入上均可见；确认 prefers-reduced-motion 已在 style.css 统一降级。
- 窄屏规则：报告 ≤820px、管理台 ≤720px、设置 ≤520px、工作台 ≤900/760px。

### 3.5 加载

- web/index.html 静态版本 ?v=28 → ?v=29。
