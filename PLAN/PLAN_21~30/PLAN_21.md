# PLAN 21 — 视觉重构（二）：正文阅读区

日期：2026-11-18　｜　状态：已完成

> 全站美化第二批。延续 PLAN 20 的令牌与语言，只做正文阅读区；不改变任何交互逻辑（JS / DOM 结构 / id / 接口一律不动）。

## 1. 需求

- 把正文阅读区从「普通滚动文本」提升为「可读的文档版面」：舒适行宽、清晰层级、克制的强调。
- 与 PLAN 20 的冷纸 + 墨蓝、衬线仅用于文档标题的分工保持一致。
- 保持现有行为：分块渲染、点击时间线滚动定位、mark 高亮、简介面板拖动与关闭都不变。

## 2. 现状

- web/reader.css：正文 15px / 1.9、左右 padding 34px、无行宽上限；标题全部无衬线加粗；高亮是整块 #ffe58a。
- 文档标签是胶囊按钮（描边 + 蓝底选中）；简介面板是蓝色系（#f7faff / #bfd3f5 / 蓝色阴影），与 PLAN 20 的墨蓝体系不一致。
- 摘要拖拽条是渐变底色条，和记录栏的细握把语言不统一。

## 3. 方案（仅 web/reader.css）

### 3.1 阅读头与文档标签

- .reader-head：白底、1px 下线、内边距 8px 20px，保持 50px 高度与右侧「报告」按钮位置。
- .doc-tab 改成**底线式索引标签**（与登录页选项卡同一语言）：
  - 无边框、6px 上圆角、默认灰色；
  - 悬停浅蓝底；
  - 选中：墨色、600 字重、底部 2px 墨蓝线。
- 标签滚动条改成令牌色（--line-strong）。

### 3.2 正文版面

- .reader-body：padding 26px 40px 64px、15.5px / 1.9、正文墨色。
- .md-block：max-width 760px、margin 0 auto 16px——每个块单独居中，滚动条仍在容器右缘，形成稳定阅读栏宽（约 49 个汉字/行，低于 80 字符上限）。
- 标题改用衬线（--font-doc），只覆盖上下外边距，保留自动左右居中：
  - h1 27px / 600，h2 21px / 600 + 1px 下划分节，h3 17px / 600。
- mark 改为柔和标记底色 --marker，2px 内边距、3px 圆角、box-decoration-break: clone，多行高亮不破形。

### 3.3 简介面板

- 面板改为白底 + 1px 上边线 + 冷色浮层阴影，去掉蓝色调。
- .summary-resize 改成与记录栏一致的居中细握把（默认低对比，悬停加深）。
- .summary-head：标题前加 6px 墨蓝小方块（与时间线节点同一标记语言），12px / 600；关闭按钮沿用 .icon-btn。
- .summary-body 13.5px / 1.8，.summary-text 15px / 1.85。

### 3.4 加载

- web/index.html 静态版本 ?v=27 → ?v=28（只刷新 CSS 缓存）。
